# Basix Pathtracing project guidance

Root basis is RTXPT1.9 including its original Assets pin. `baseline/rtxpt-1.9` and `rtxpt-1.9-baseline` identify unchanged upstream303b408. B1 at7010bb4 means the implemented RTXDI3.1 runtime/API migration for existing DI/GI; no new ReSTIR PT path is implied; B2 means ReSTIR PT integration with selectable DI/GI and explicit contribution ownership; B3 means PT++ activation/extensions, with inherited runtime mechanisms recorded separately. `External/RTXDI-SDK` is reference-only until an explicit integration is implemented. Preserve original SDK/component licenses.

Read Docs/Research/README.md, ROADMAP.md, PTPP_AUDIT.md and Benchmarks/versions.json. Distinguish source inspection, planned work, active features and measured results. Paper numbers and synthetic metric tests are not local renderer results. B0 retains runtimea14e079; B1 pins official runtimef12037f. Read B1_RESULTS.md for measured scope.

Changes inside submodules require explicit ownership and reachable child commits. Preserve exact baseline and scene pins for comparisons. Document estimator PDFs/Jacobians/RNG and bias controls; validate raw HDR before reconstruction, then quality, total timing, VRAM and temporal behavior. Exclude paper caches, credentials and private host telemetry from exports.

B2 ReSTIR PT integration is in progress with scoped static opaque HDR validation and cap-verified native-control timings; it is not promoted. See Docs/Research/B2_RESULTS.md for the current measured checkpoint. B3 is reserved for PT++ changes. Read Docs/Research/B2_IMPLEMENTATION.md and Benchmarks/versions.json; preserve immutable B0/B1 and reject overlapping GI/PT lighting without a valid partition/MIS. Future benchmarks require explicit uncapped renderer controls plus recorded driver/external-cap coverage.
