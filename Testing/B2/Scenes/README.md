# B2 opaque transport diagnostic

Original procedural geometry/materials created for this project; no source assets are copied. This is a separate diagnostic, not one of the original RTXPT benchmark scenes. Embedded glTF geometry includes diffuse walls, an emissive ceiling patch and a rough opaque metal occluder. Use a nonbinding diffuse cap and fixed pinhole/raw settings. Its existence does not validate PT transport; record observed renderer activation, reference error, replay/history behavior and failures separately. Original Assets repository is untouched.
