reportedGradient-Domain ReSTIR Path Tracing

Resample paired-pixel paths directly in gradient space, with adaptive edge-aligned spatial reuse and positive/negative reservoirs to reduce sign noise; reconstruct using a separate primal Area ReSTIR image.

Use / implication
RTXPT research branch: separate gradient reservoirs, primal pass and reconstruction interface. RTXDI core can supply path shifts but cannot obtain this by merely changing a spatial-neighbor picker. Decision: Promising detail preservation, but a separate estimator/reconstruction architecture follows the seven requested sampling priorities.
Context
Publisher full-text HTML: Sections 4–6; direct PDF exceeded web size limit. Falcor, RTX 5090, Ryzen 5900X, 1920×1080 moving camera. L2 Poisson reconstruction costs 11 ms; L1 costs 300 ms. L2 cost is included in equal-time comparisons.
Confidence
high
Strengths
Primary-source mechanism evidence with explicit scope.
Limits
Assumes affine object transforms. High-frequency temporal turbulence remains without temporal gradients; reconstruction is an additional cost. Neural reconstruction efficiency is prospective, not demonstrated as a DLSS integration.

supports: P06 · Sections 4.1–4.4, 5 Results, 6 Discussion and Conclusion; Figures 9–12 — Reading extent and performance context are source-specific.

Mutate selected reservoir samples using Metropolis–Hastings, usually after temporal reuse; update the contribution weight by the old/new target-function ratio before further resampling.

Use / implication
Optional RTXDI DI/PT decorrelation stage, especially when long temporal history is valuable. Compare to compatible-neighbor selection rather than assuming gains add. Decision: Revisit if improved neighbors and PT++ still leave visible boiling/blotches.
Context
Publisher full-text method Section 3 and limitations Section 7; indexed paper excerpts. Demonstrated in DI and PT; mutations address correlation and duplicate-sample impoverishment.
Confidence
high
Strengths

Limits
Non-negligible runtime; can improve perceptual correlation without lowering MSE. It is not a discovery mechanism for missing important transport, and even unlimited mutations need not remove all correlations.
